# Examples

Short, linked documents that show what HyperTeX can do: equations and cross-references, tables, figures that
move, sliders that redraw plots, theorems with collapsible proofs, step-by-step derivations, links between files,
and references. Each example is a small set of files in different formats (HyperTeX, LaTeX, Markdown and HTML)
that link to one another.

- **Open in HyperTeX** opens the file in the HyperTeX viewer (version 0.7.2 or later, [download](download.md)).
  Follow the links, move the sliders, and press ✎ to edit the source beside a live preview.
  **Save As** then keeps a copy on your computer, together with every file it uses.
- **Read on the web** shows a plain HTML copy made with `htex build`. It works in any browser, but sliders
  only change the numbers there; the figures redraw in HyperTeX.
- **Source** shows the file as written.

You can also open the list of all examples in HyperTeX at
[htex://krunyx.com/examples/index.htex](htex://krunyx.com/examples/index.htex).

## Add your own

Each example is a folder under
[`examples/`](https://github.com/krunyx/krunyx.com/tree/main/examples) in the website's repository, with an
`example.yml` that gives its title, a summary and the files to list. A new folder with an `example.yml` appears
here and in the HyperTeX list automatically.
