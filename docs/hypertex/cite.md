# 인용하기

연구에 HyperTeX를 썼다면 아래 형식으로 인용해 주세요.

```bibtex
@software{hypertex,
  author  = {{krunyx}},
  title   = {HyperTeX: a TeX-based hypertext format and browser},
  version = {0.1.0},
  year    = {2026},
  url     = {https://krunyx.com/hypertex/}
}
```

!!! note "DOI 준비 중"
    릴리스마다 영구 식별자(DOI)를 붙일 수 있도록 Zenodo 연동을 준비하고 있습니다.
    DOI가 발급되면 이 페이지와 저장소의 `CITATION.cff`에 함께 올립니다.
