# Cite HyperTeX

If you used HyperTeX in your research, please cite it as follows.

```bibtex
@software{hypertex,
  author  = {{krunyx}},
  title   = {HyperTeX: a TeX-based hypertext format and browser},
  version = {0.3.0},
  year    = {2026},
  url     = {https://krunyx.com/hypertex/}
}
```
