# 변경 기록

새 버전을 낼 때마다 맨 위에 항목을 추가합니다.

## v0.1.0 { #v0-1-0 }

2026년 10월. 첫 공개 버전입니다.

- HyperTeX 2.0 파서: 매크로 확장, 계산식, 문서 트리
- HTML과 MathML 변환기
- TikZ, pgfplots 부분집합을 SVG로 그리는 그림 렌더러
- PySide6 기반 데스크톱 뷰어: 탭, 찾기, 확대, 원본 보기, 테마
- `htex serve`, `htex build`로 일반 브라우저와 정적 웹사이트 지원
- 기존 `.tex` 파일 호환 모드
- macOS, Windows, Linux 설치 파일
