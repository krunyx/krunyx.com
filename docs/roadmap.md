# 로드맵

krunyx의 이름은 한국(KR)과 유닉스(Unix) 계열 운영체제에서 왔습니다.
과학자와 엔지니어가 믿고 쓸 수 있는 컴퓨팅 환경을 하드웨어부터 응용 프로그램까지 한 흐름으로 만드는 것이 목표입니다.

아래 단계는 순서대로 진행합니다. 각 단계가 다음 단계의 기반이 됩니다.

## 1. HyperTeX { #hypertex }

**지금 쓸 수 있습니다.** LaTeX 문법으로 쓰는 웹 문서 형식과 그 브라우저입니다.
krunyx OS의 기본 문서 브라우저가 됩니다.

[HyperTeX 내려받기](hypertex/download.md)

## 2. krunyx OS { #os }

**개발 중입니다.** 보안을 강화한 리눅스 기반 운영체제입니다.
기본 설정만으로 안전하고, 무엇이 실행되는지 사용자가 확인할 수 있는 시스템을 지향합니다.

## 3. AI 계층 { #ai }

**연구 중입니다.** AI 에이전트가 사용자의 파일과 프로그램을 다루더라도,
허락한 범위 안에서만 움직이도록 OS 수준에서 경계를 두는 계층입니다.

## 4. 하드웨어 { #hardware }

**계획 단계입니다.** 위 세 층에 맞춰 설계한 컴퓨터입니다.
소프트웨어와 하드웨어를 함께 설계해야 보안과 사용성을 함께 얻을 수 있다고 봅니다.
