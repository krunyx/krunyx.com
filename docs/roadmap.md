# Roadmap

The name krunyx comes from KR, for Korea, and the Unix family of operating systems.
Our goal is a computing environment that scientists and engineers can trust, designed as one piece from the hardware to the applications.

The stages below happen in order. Each one is the foundation for the next.

## 1. HyperTeX { #hypertex }

**Available now.** A web document format written in LaTeX syntax, and a browser to read it.
It will become the default document browser of krunyx OS.

[Download HyperTeX](hypertex/download.md)

## 2. krunyx OS { #os }

**In development.** A security-hardened operating system built on Linux.
We aim for a system that is safe by default and lets you see exactly what is running.

## 3. AI layer { #ai }

**In research.** An OS-level boundary that lets AI agents work with your files and programs
while keeping them inside the limits you grant.

## 4. Hardware { #hardware }

**Planned.** Computers designed around the three layers above.
We believe security and usability come together only when software and hardware are designed together.
